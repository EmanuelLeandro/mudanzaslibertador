# Mudanzas Libertador BA — sitio demo

Sitio estático (HTML + CSS + JS, sin build). Abrí `index.html` con doble clic o subí la carpeta a Netlify (arrastrar y soltar) o GitHub Pages.

## Para completar antes de publicar
- Dominio: reemplazar `https://www.tu-dominio.com.ar/` en `index.html` (canonical, og:url, og:image y JSON-LD).
- Testimonios: hoy la sección enlaza a las historias destacadas de Instagram. Si el cliente pasa reseñas reales (con permiso), se pueden agregar como tarjetas.
- Fotos: son capturas de los posts de Instagram (640 px). Con fotos originales en alta se vería mejor.
- Logo: `assets/img/logo.jpg` es el original (150 px). `logo-mark.svg`/`favicon.svg` son una versión simplificada; ideal reemplazar por el logo en vector.
